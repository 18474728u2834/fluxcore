# Nexus V4 — Hyra-inspired workspace

## Goal
Create a new Nexus version that feels like a deliberate evolution of the real product: V1’s slim navigation and generous workspace combined with V3’s useful search, status summary, and configurable operational panels.

## Visual direction
- Keep Fluxcore’s established near-black, graphite, white, and restrained `#2f74a8` blue palette.
- Use Outfit for headings and Figtree for interface text.
- Prefer flat matte surfaces, thin borders, 4–8px corners, and precise alignment.
- Remove ambient glow, glass blur, oversized radii, floating effects, decorative gradients, and invented dashboard content.
- Use short, fast state transitions only.

## Build
- Add Nexus V4 as a selectable Nexus configuration version without removing V1–V3.
- Build a responsive V4 shell with a slim icon rail, workspace switcher, compact global search, account menu, mobile drawer, and the existing full navigation.
- Build the V4 dashboard using real Fluxcore data: welcome image, birthdays, new members, staff in game, upcoming sessions, and recent activity.
- Preserve owner-controlled card visibility and ordering.
- Add V4 to the existing Nexus settings selector so workspace owners can enable it.
- Keep all existing permissions, links, search behavior, and workspace branding intact.

## Verification
- Open the populated demo workspace on desktop and phone sizes.
- Confirm navigation, search, account actions, cards, empty states, and configured hero behavior remain usable.
- Confirm the app builds without errors.
